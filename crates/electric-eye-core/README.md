# electric-eye-core

Shared serializable process, file, and network event types for
[Electric Eye](https://github.com/jamesmcm/electric-eye), a read-only Linux
activity monitor. This library does not attach probes or start a daemon.

For the query client, install `electric-eye-cli`. For the collector, see
[electric-eyed](https://crates.io/crates/electric-eyed) and the project's
[installation instructions](https://github.com/jamesmcm/electric-eye#install-on-arch-linux).
